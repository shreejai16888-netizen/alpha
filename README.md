## Publish using GitHub Pages
1. Sign in at https://github.com and create a new **Public** repository named `alpha-publication-7-days`.
2. Upload `index.html` to the repository root and click **Commit changes**.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. Wait a few minutes; GitHub Pages displays the live URL on that page.
